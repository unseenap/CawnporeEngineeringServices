# CES Search Visibility and SEO Maintenance Plan

## Document purpose

This file is the working SEO roadmap for **Cawnpore Engineering Services (CES)** and its production website:

- Primary domain: `https://ceservices.co.in`
- Business focus: HVAC consultancy, design, installation and lifecycle services
- Primary market: Kanpur, Uttar Pradesh and suitable projects across India
- Main conversion: qualified calls, WhatsApp conversations and quote requests

Update this document whenever an SEO task is completed, a target changes, a new article is published or Search Console reveals a new opportunity.

> SEO cannot guarantee the first position for a query. The objective is to build the strongest relevant, technically accessible and trustworthy HVAC resource possible, then improve it using measured search data.

### Keyword selection rules

- Prefer keywords that accurately describe services CES actually provides.
- Separate commercial intent (“HVAC contractor”) from learning intent (“how basement ventilation works”).
- Use location terms only when CES genuinely serves the location.
- Use Search Console query data before expanding to new phrases.
- Avoid creating duplicate pages for tiny keyword variations.
- Never claim “best”, “number one” or “top HVAC company” as a fact without independent evidence.
- A page may answer a query such as “how to choose a top HVAC company” while demonstrating CES’s qualifications honestly.

## 7. React, HTML and indexability requirement

The site may remain a **React/Next.js application**. Blogs do not need to be hand-written as separate `.html` files.

What matters is the final response Google receives:

- Article title, headings, paragraphs, links, author, dates and image descriptions must render as semantic HTML.
- Next.js server rendering or static generation should produce the article HTML before client JavaScript runs.
- Use elements such as `<article>`, `<header>`, `<main>`, `<nav>`, `<h1>`, `<h2>`, `<p>`, `<img>` and `<a>`.
- Do not load the main article only after a browser-side API request.
- Avoid putting meaningful article text inside images, canvas or decorative animation.
- Each article must have a permanent URL, metadata, canonical link and sitemap entry.

Recommended implementation options:

1. Store each article as structured TypeScript/JSON/MDX content.
2. Generate `/blogs/[slug]` pages using Next.js static generation.
3. Render metadata per article through Next.js metadata APIs.
4. Render `BlogPosting` and breadcrumb JSON-LD per article.

Therefore, **React works well for SEO when the content is server-rendered or statically generated into HTML**. A separate handwritten HTML website is unnecessary.

## 17. Practices to avoid

- Keyword stuffing in headings, paragraphs, alt text or footers
- Copying or lightly rewriting competitor pages
- Publishing dozens of low-value AI articles
- Fake authors, fake locations, fake projects or invented certifications
- Doorway pages for cities CES does not genuinely serve
- Buying reviews or bulk backlinks
- Hiding text for search engines
- Using misleading “top”, “best” or “number one” claims
- Changing dates without meaningful updates
- Deleting useful URLs without redirects
- Allowing attractive animation to delay or conceal core content

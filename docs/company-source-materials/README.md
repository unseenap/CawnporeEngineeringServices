# Company source materials

This directory preserves the original files supplied by Cawnpore Engineering
Services. These files are reference material and are not served directly by the
website.

## Directory structure

- `brand/` contains the original company logo.
- `company-profile/` contains the supplied PDF and PowerPoint profiles.
- `service-reference-images/` contains original service-related imagery.
- `project-reference-images/` contains original client and project imagery.

Production-ready copies used by the website live in `public/`. Content derived
from these materials lives in `data/`.
